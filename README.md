# Produse - listă simplu înlănțuită

Gestiunea produselor într-o listă simplu înlănțuită.

## Funcționalități

- citirea produselor din `fisier.txt`
- valoarea totală a stocului
- afișarea produselor sub un preț maxim
- modificarea prețului unui produs
- ștergerea unui produs după cod
- dezalocarea memoriei

## Structura de date

`Produs`: cod, denumire, preț, cantitate.

## Rulare

Se deschide `ProduseListaSimpla.sln` în Visual Studio. Fișierul `fisier.txt` trebuie să fie în directorul de lucru.
